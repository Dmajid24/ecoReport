<h1>Eco Report</h1>
Eco Report merupakan sistem berbasis web yang digunakan untuk melaporkan permasalahan kebersihan di lingkungan kampus BINUS. Sistem ini bertujuan untuk mempermudah proses pelaporan, mempercepat penanganan, serta meningkatkan transparansi status laporan.

<h2>Fitur Utama</h2>
<li>CRUD Laporan Kebersihan</li>
<li>CRUD Laporan Kebersihan</li>
<li>CRUD Kategori Masalah</li>
<li>CRUD User (Admin dan Petugas)</li>
<li>Proses penanganan laporan (pending, on progress, done)</li>
<li>Validasi autentikasi dan otorisasi pengguna</li>
<li>Validasi penghapusan akun</li>
<li>Validasi penghapusan kategori</li>
<li>Tampilan dashboard sesuai peran pengguna</li>
